# Vercel Setup

Run the following commands in the project folder:

```bash
npm install
npm install -g vercel
vercel login
vercel link
vercel dev
```

## Notes
- `vercel login` requires a Vercel account.
- `vercel link` connects the local project to your Vercel project.
- `vercel dev` starts the local development server.
